# Phull Insights preview source

`build-preview.js` is the only generator for the current non-production preview.

The generated `dist/` directory is intentionally search-blocked. Do not remove preview `noindex` metadata, open `robots.txt`, generate a production sitemap or deploy a saved version without completing `release-checklist.md` and recording owner approval.

Control files:

- `truth-lock-register.md`
- `case-clearance-log.md`
- `journeyiq-usage-inventory.md`
- `release-checklist.md`
- `validate-preview.js`
