# phullinsights-site

The Phull Insights corporate website—an operations advisory and technology
practice—deployed to GitHub Pages at https://phullinsights.com.

The current production site is generated by the plain-static source in
work/ and published from the committed dist/ directory. The earlier Next.js
source remains in the repository as historical implementation source; the
Pages workflow does not build or deploy it.

## Current structure

- work/build-preview.js — shared static-site generator
- work/build-production.js — production build, redirects, sitemap and CNAME
- work/validate-production.js — production release checks
- work/*.md — truth locks, case clearance, redirects and release decisions
- dist/ — production-ready static site deployed by GitHub Pages
- dist/CNAME — the custom domain for GitHub Pages
- .github/workflows/deploy-pages.yml — deploys dist/ on every push to main

## Local development

Run:

    npm run build:site
    npm run validate:site
    python3 -m http.server 3000 --directory dist

Then visit http://localhost:3000.

## Editing content

Site copy and route definitions live in work/build-preview.js. Update the
truth-lock and release-control files in work/ at the same time as content.
Run both production scripts before committing dist/.

## Deploying

Every push to main publishes the validated, committed dist/ folder through
the GitHub Pages workflow. The custom domain is phullinsights.com.

The production output is plain HTML, CSS and JavaScript. The Contact page
uses separate Client, Recruiter and Peer email routes until a hosted-form and
spam-protection provider are selected. Analytics remains disabled until a
platform and consent implementation are approved.
